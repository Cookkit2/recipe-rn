## 2024-06-25 - Optimize Sequential Caching in Map Index
**Learning:** When building a Map index where the "first occurrence wins" (usually implemented with `if (!map.has(key)) map.set(key, value)`), iterating forwards requires an expensive `.has()` lookup on every single iteration. Using `flatMap` and `new Map(iterable)` avoids `.has()` lookups but allocates many intermediate arrays, causing CPU/GC overhead.
**Action:** Instead of `flatMap` or `.has()` checks, use a single-pass reverse iteration (`for (let i = arr.length - 1; i >= 0; i--)`). Since earlier items are processed last, they naturally overwrite duplicates, perfectly preserving the "first occurrence wins" logic with zero intermediate allocations and no redundant lookups.
