## 2026-05-16 - Batched Update Optimization for Challenge Metrics
**Learning:** Sequential `await` statements inside high-frequency `for` loops against local databases (like WatermelonDB) incur significant N+1 latency blocks, drastically impacting UI smoothness on React Native. Re-implementing repository progress status transitions as batched functions allows single-fetch and multi-write operations, improving throughput.
**Action:** When updating multiple challenges during high-frequency events, aggregate reads via `database.query(Q.oneOf(ids))` or iterate with `Promise.all` instead of standard sequential loops to alleviate JS thread stalling and batch DB transactions.
