## 2023-11-20 - [Batch API Optimization for N+1 Query Anti-Pattern]
**Learning:** Using `Array.map` combined with `await Promise.all` to fetch related database records (like fetching `userAchievement` inside `getProgress`) acts functionally as a serial queue causing significant N+1 delays in SQLite, especially noticeable with large arrays (e.g., rendering the "Achievements" list). When calculating dependent fields across loops, extracting and using JSON.stringify for the dependency as a caching key minimizes repeat calculation while remaining safe for varied sub-conditions.
**Action:** When a method processes multiple records, identify loop-internal database lookups or calculations, extract the unique dependencies, and perform a single batch-fetch upfront using methods like `getBy...Ids`. Store the results in a lookup map (or use stringified representations for complex config objects) to enable O(1) matching within the iteration loop to avoid N+1 querying.
