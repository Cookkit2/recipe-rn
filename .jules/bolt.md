## 2024-05-24 - Batch Operations in WatermelonDB
**Learning:** Sequential writes using `database.write` in a loop in WatermelonDB create multiple SQLite transactions, leading to significant I/O overhead (N+1 query bottleneck). Tests might also fail if not run in a proper React Native environment, but replacing loop writes with `database.batch` is universally recognized as the fastest method.
**Action:** Always prefer `database.batch()` over looping single inserts (`database.create` / `database.update`). Construct prepared models using `.prepareCreate` or `.prepareUpdate` and push them into an array to be passed to `database.batch()` inside a single `database.write` block.
